How it works

No server, no waiting in a queue. Your image is processed entirely on your own device using your browser's built-in image tools.

Processed locally

Your file is read straight into browser memory. It's never transmitted to any server, ours or anyone else's.

Instant results

Moving the quality slider recompresses the image immediately, so you see the new file size right away.

Batch download

Download images one at a time, or grab the whole batch as a single zip file when you're finished.

Frequently asked questions

Does this tool upload my photos anywhere?

No. Every image is processed locally in your browser. Files are never sent to a server.

What image formats are supported?

You can compress JPG, PNG and WebP files, and convert between those three formats on export.

Will compression reduce my image resolution?

Not unless you turn on the optional max-width resize. By default only quality is reduced, not pixel dimensions.

Is there a file size or file count limit?

No hard limit is enforced by the tool. Large batches are limited only by your device's available memory.
